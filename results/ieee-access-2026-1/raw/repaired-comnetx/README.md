# Repaired ComNetX Raw Reruns

This directory is reserved for campaigns produced by
`scripts/paper/ieee_access_repaired_comnetx_72h/run_queue.py`. Historical
smart-mode measurements with hierarchy depth `L >= 2` are provisional and
must not be copied here. A valid campaign records the repaired source,
environment, hardware, input-data, bootstrap-cache, stdout, and output hashes;
passes hierarchy/namespace and production-profile parity gates; and keeps
failed or unfavorable runs. LD-Leiden comparator data stays in the sibling
`raw/ldleiden` namespace.
