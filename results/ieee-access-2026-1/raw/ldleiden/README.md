# Raw LD-Leiden Measurements

Campaign directories in this location are generated by
`scripts/paper/ieee_access_ldleiden_72h/run_protocol.py`. The committed protocol
keeps the all-graph smoke run separate from the five short and three long
measured repetitions. Do not copy historical LD-Leiden timings into this
directory: accepted campaigns must expose split optimization, update, and
end-to-end clocks and pass `validate_results.py`.
