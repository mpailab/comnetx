# Baseline Implementations

This reduced ICDM branch keeps only external baseline code used by the
canonical `results/icdm-2026-1` measurement bundle.

- DMoN: `baselines/DMON/graph_embedding/dmon`
- FLMIG: `baselines/FLMIG_algorithm`
- MAGI: `baselines/MAGI`
- MFC-TopoReg: `baselines/MFC-TopoReg`
- PRGPT: `baselines/PRGPT`
- S2CAG: `baselines/S2CAG`

Leiden and DF-Leiden are provided through Python packages/bindings rather than
vendored source in this directory.
